Settings

Entries are saved as a CSV file (Excel opens it) in a private GitHub repo. The app won't save to a public repo. Set this up once on each phone.

Save to GitHub

Use a fine-grained token limited to just that private repository with Contents: Read and write. The token stays on this phone only.

Files

Import reads Excel, CSV or text files. It needs a date/time column and an event column (Poop, MiraLAX or Gas-X). A Bristol type column is optional. Duplicate rows are skipped.
