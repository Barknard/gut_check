Removes every entry from the app and from every place it's saved. You'll be asked to confirm, and a backup is kept inside the app.

Keep the log safe

Every tap is saved inside this app. But if the phone is lost, reset, or the browser's data is cleared, anything saved only there is gone.

This setup saves the log in more than one place, so one copy can always be recovered. It takes about 5 minutes.

Step 1 of 3

Save a file on this phone

Pick a folder on the phone and the app keeps a spreadsheet there. Every tap goes straight into it, and Excel or Google Sheets can open it.

  1. Tap Create new file.
  2. Choose a folder. Best: a Google Drive folder, so the file is also copied off the phone. Documents or Downloads also work.
  3. Keep the name gut-check.xlsx (Excel) or change the end to .csv, then tap Save.
  4. If the phone asks whether Gut Check may edit the file, tap Allow.

Already have a Gut Check file, or "Create new file" won't save? Use Use existing file and pick it. Nothing already in it is lost; the two are combined.

iPhones don't let any website keep a file up to date by itself. Instead:

  • Set up the online backup in the next step. It saves automatically and is the safest option on iPhone.
  • Also, every week or two, tap Save a copy to Files below and choose iCloud Drive or On My iPhone.

Step 2 of 3 · Recommended

Back up online (free)

Saves to a private storage space on GitHub that only you can see. It saves automatically, keeps every past version, and lets another phone use the same log.

  1. Sign in to GitHub, or make a free account. Open GitHub
  2. Create the storage space. The name gut-check-data and Private are filled in. Check that Private is selected, then press Create repository.
  3. Create an access key. On that page:
    • Under Repository access, choose Only select repositories, then pick gut-check-data.
    • Check that Contents says Read and write.
    • Press Generate token, then copy the key it shows.
  4. Come back here, fill in the boxes below, and press Connect.
Advanced

The key stays on this phone. The app refuses to save to a public repository.

Step 3 of 3

Bring in existing data

A file or GitHub you just linked has already been read in. Use this if there's another log file to add, such as a copy saved earlier. Nothing is overwritten and duplicates are skipped.

Automatic backups inside the app

The app keeps a copy each day for the last 30 days. Restore puts back anything that's missing and doesn't remove anything.

All set

The badge at the top of the app shows how many places the log is saved in. If saving ever stops working, a warning appears on the home screen.

Delete all entries?

You'll have 10 seconds to undo. After that it can't be undone, so download a backup first if you might want this data later.
