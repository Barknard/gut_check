Entries are always kept inside the app on this phone. You can also save them to a spreadsheet file on the phone, or to a private GitHub repo so they're backed up and other phones can use them. Pick one.

Save to a file on this phone

No file linked yet.

Choose any folder, e.g. Downloads, Documents or Google Drive. Every tap is saved straight into that file, and the app reads it again whenever it opens, so changes made in Excel show up too. End the name in .xlsx for an Excel file or .csv for a plain one. If "Create new file" won't save, pick an existing spreadsheet with "Use existing file" instead.

This browser can't stay linked to a file. iPhone and iPad don't allow that for any website. Tap Save copy to Files and choose a folder (On My iPhone, iCloud Drive…), and use Import file below to read a copy back in.

Or save to GitHub

Use a fine-grained token limited to just that private repository with Contents: Read and write. The token stays on this phone only.

Files

Import reads Excel, CSV or text files. It needs a date/time column and an event column (Poop, Vomit, MiraLAX or Gas-X). A Bristol type column is optional. Duplicate rows are skipped.

Start over

Removes every entry from the app and from the linked file or GitHub file. You'll be asked to confirm first.

Delete all entries?

You'll have 10 seconds to undo. After that it can't be undone, so download a backup first if you might want this data later.
